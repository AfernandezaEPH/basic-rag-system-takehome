## 🎯 Descripción del Proyecto

Primera implementación de un sistema RAG (Retrieval-Augmented Generation) usando una aproximación directa con ChromaDB como base de datos vectorial y SentenceTransformers para embeddings. Esta es la **versión inicial** antes de evolucionar a frameworks más complejos.

### ✨ Características de esta Primera Iteración

- ✅ **Implementación Directa**: Sin frameworks complejos, código claro y entendible
- ✅ **ChromaDB Nativo**: Base de datos vectorial persistente
- ✅ **SentenceTransformers**: Embeddings con all-MiniLM-L6-v2
- ✅ **Dataset JSON**: Papers científicos estructurados
- ✅ **Búsqueda Semántica**: Similaridad coseno implementada
- ✅ **Demo Interactivo**: Jupyter notebook funcional
